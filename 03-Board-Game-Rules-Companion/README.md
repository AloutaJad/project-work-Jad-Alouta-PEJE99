## Application Name
**RuleMate**

## Application Purpose
RuleMate is a mobile-friendly web application that helps players find answers to questions about board-game rules. Users can upload or select a supported rulebook and ask questions in natural language. The application searches the relevant rulebook content and provides an answer together with the corresponding page or section reference.

## Why I Want to Develop This Application
I want to develop this application because board-game rulebooks can be long and difficult to search during a game. Players often need a quick answer to a specific situation instead of reading through an entire rulebook.

The application combines document search with an AI-based question-answering system. An important part of the project is that answers should be supported by relevant sections of the original rulebook, making the information easier to verify.

## Main Functions
- Upload or select a board-game rulebook.
- Select the game and version.
- Ask questions in natural language.
- Search the relevant parts of the rulebook.
- Generate an answer based on retrieved content.
- Show page and section references.
- Support different editions and expansions.
- Save questions and notes.
- Clearly distinguish official rules from user-created house rules.

## Expected Result
The final application should help players find reliable rule information quickly while keeping the original rulebook source visible for verification.
