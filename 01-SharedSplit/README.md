**SharedSplit**

## Application Purpose
SharedSplit is a mobile-friendly application designed to make splitting group expenses simple and accurate. A user can take a photo of a receipt, add the people involved, identify which items belong to which participants, and calculate how much each person should pay.

## Why I Want to Develop This Application
I want to develop this application because splitting receipts manually can be time-consuming and can easily lead to mistakes, especially when a receipt contains many items or when different people consumed different products. The application provides a practical solution by organizing receipt information and automatically calculating each participant's share.

The project is also suitable for studying how OCR and AI-based information extraction can be combined with a user-friendly mobile/web interface. The user can review and correct extracted information before the final calculation, which makes the system more reliable.

## Main Functions
- Photograph or upload a receipt.
- Extract receipt information using OCR and AI.
- Allow the user to review and edit extracted items.
- Add the payer and participants.
- Assign individual items to one or more participants.
- Support equal, percentage-based, and fixed splitting.
- Calculate the amount owed by each participant.
- Show balances and settlements.
- Keep expense history.
- Export expense information.

## Expected Result
The final application should reduce the time and effort required to divide shared expenses while keeping the calculation transparent and editable.
