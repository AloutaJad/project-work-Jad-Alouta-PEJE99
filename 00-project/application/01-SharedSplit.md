# SharedSplit

## My interpretation of the brief

The project is a web application for splitting shared expenses. A user can enter a receipt, add the people involved, assign expenses to participants, and calculate how much each person should pay.

## Why I want to develop this application

Splitting a receipt manually can be time-consuming and can lead to calculation mistakes. The application provides a simple way to organize the expenses and calculate each participant's share automatically.

## Relevant experience and background

I have experience with web development, databases, JavaScript, and Git through coursework and personal projects. I am interested in developing a practical application with a clear and manageable scope.

## Proposed approach

I would first design the expense and participant data model and implement the basic calculation logic. I would then build a simple user interface for entering expenses and assigning them to participants. Finally, I would add the database and test the calculations with different examples.

## Initial plan

1. Define the expense, receipt, and participant data.
2. Design the main user interface.
3. Implement expense splitting and calculation logic.
4. Add database persistence.
5. Test different splitting cases and correct calculation errors.

## Additional information

The main focus will be a simple and reliable expense-splitting application. Advanced OCR or AI features will not be required for the core implementation.
