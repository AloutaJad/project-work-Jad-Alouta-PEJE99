# League of Legends Match Data Warehouse

## My interpretation of the brief

The project is a data warehouse and analytics application for League of Legends match data. The system will store structured match information and allow users to analyze statistics by player, champion, role, and time period.

## Why I want to develop this application

Match data can contain many statistics that are difficult to compare manually. A structured database and simple analytical queries can make historical performance easier to understand and compare.

## Relevant experience and background

I have experience with databases, SQL, web development, and Git through coursework and personal projects. I am interested in learning more about organizing and analyzing structured data.

## Proposed approach

I would first define a simple database structure for match and player statistics. I would then insert or import sample match data and create SQL queries for basic analysis. A simple web interface can display the results using tables and charts.

## Initial plan

1. Define the required match and player data.
2. Design the database structure.
3. Add sample or available match data.
4. Implement analytical SQL queries.
5. Create a simple interface for viewing statistics.
6. Test the queries and displayed results.

## Additional information

The project will focus on a manageable analytical database rather than a complex large-scale system. The main goal is to demonstrate structured data storage and statistical analysis.
