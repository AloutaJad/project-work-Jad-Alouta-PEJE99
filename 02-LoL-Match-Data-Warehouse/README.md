## Application Purpose
This application is a data warehouse and analytics system for League of Legends match data. It collects match information, transforms it into a structured analytical database, and allows users to analyze performance by player, champion, role, patch, time period, and match type.

## Why I Want to Develop This Application
I want to develop this application because it provides a practical way to understand how large amounts of structured data can be collected, transformed, stored, and analyzed. Instead of looking at individual match results separately, the system can organize the data into a warehouse that makes historical analysis easier.

The project also gives me the opportunity to work with SQL, ETL/ELT processes, dimensional data modeling, analytical queries, and business intelligence concepts in one application.

## Main Functions
- Collect match data through the Riot API.
- Store raw data in a staging area.
- Transform the data into a dimensional warehouse.
- Analyze players, champions, roles, patches, and match types.
- Generate analytical SQL queries.
- Compare performance across different periods.
- Provide statistics and visual analysis.
- Test and improve query performance.

## Expected Result
The final application should provide a structured environment for analyzing historical League of Legends match data and demonstrate how a data warehouse can support efficient analytical queries.
